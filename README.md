# iNews — חדשות בקצב שלך

אתר חדשות בעברית שמסכם ידיעות ממקורות רבים, בלי הטיה פוליטית, ומתאים אותן לזמן ולרגישות של הקורא.

שלושה דברים שאתרי חדשות מסורתיים לא נותנים:

1. **התאמה אישית.** הקורא בוחר תחומים (עוקב / רגיל / בלי) ומילים שחשוב לו לעקוב אחריהן. ההעדפות נשמרות בדפדפן בלבד, ללא התחברות.
2. **ניסוח ניטרלי.** כל ידיעה נכתבת מחדש מכמה מקורות. בנושאים שנויים במחלוקת מוצגות הטענות של כל צד, ומתחת לידיעה מוצג איזה חלק מהקשת הפוליטית כיסה אותה ואיזה לא.
3. **שליטה בריגוש ובזמן.** הקורא בוחר כמה זמן יש לו (2 / 5 / 10 דקות או בלי הגבלה) ואיזה רמת ריגוש הוא רוצה (רגוע / מאוזן / הכול). האתר בונה בריף שנכנס בדיוק בזמן הזה. ידיעה כבדה אבל חשובה לא נעלמת: היא מופיעה בניסוח מאופק.

## מבנה

```
server/   Node 22 + Express 5. איסוף, עיבוד ב-AI, API והגשת הלקוח
client/   React 19 + Vite 7 + Tailwind 4
```

### צינור העיבוד (`server/src/pipeline`)

1. `ingest.js` מושך RSS ממקורות `server/src/config/sources.js` (כולל סימון `lean` עריכתי לכל מקור, ודגל `verified`).
2. `cluster.js` מקבץ כותרות לאותו אירוע. הקריאה ל-AI מקבלת כותרות בלבד. אם היא נכשלת יש גיבוי דטרמיניסטי לפי חפיפת מילים.
3. מזהי כתבות יציבים: כתבה שנשארת אותו אירוע שומרת את המזהה שלה בין ריצות, ולכן לא מחושבת מחדש.
4. `enrich.js` מבקש מ-AI (קריאה אחת לכל כתבה, tool-use כפוי, טמפרטורה 0): כותרת ניטרלית, תקציר, נקודות, "למה זה חשוב", `intensity` 1–5, `importance` 1–5, `sourceHeat`, `graphic`, נושאים, ישויות, תקציר מאופק, `contested`, ו-`framing`. תוויות הנטייה של המקורות לא נשלחות למודל.
5. `validate.js` מוודא את הפלט. מספרים שלא מופיעים בטקסט המקור נפסלים (משפט עם מספר מומצא מוסר או מוחלף בכותרת המקור).
6. `coverage.js` מחשב באופן דטרמיניסטי את כיסוי הקשת הפוליטית ואת ה"נקודה העיוורת".
7. השמירה היא קבצי JSON בתיקיית `DATA_DIR` (`stories.json`, `meta.json`, `articles.json`), בכתיבה אטומית.

### אלגוריתם הבריף (`client/src/lib/briefing.js`)

- תקרת ריגוש: רגוע 2, מאוזן 3, הכול 5.
- ידיעה כבדה עם `importance` ≥ 4 מוצגת בניסוח מאופק ולא מוסתרת. ידיעה גרפית מוסתרת רק במצב "הכול".
- ציון: חשיבות, מעקב אחרי תחום, מילות מפתח, מספר מקורות, וטריות, פחות ריגוש.
- שלושה מעברים: מילוי בתקצירים קצרים, מילוי בכותרות בלבד, ושדרוג לגרסה מלאה אם נשאר זמן.
- מה שלא נכנס לזמן ומה שסונן לפי ריגוש תמיד מופיע ברשימות מתקפלות. שום דבר לא נעלם בשקט.

## הרצה מקומית

```bash
npm run install:all
cp server/.env.example server/.env      # הכנס ANTHROPIC_API_KEY
npm --prefix server run refresh          # ריצה אחת + דוח תקינות לכל מקור
npm --prefix server start                # שרת על :3000
npm --prefix client run dev              # ממשק על :5173 עם proxy ל-/api
```

**מצב הדגמה** (ללא מפתח, ללא רשת, עם ידיעות ומקורות בדויים):

```bash
npm run demo
```

## הרצה ב-GitHub Codespaces

1. בגיטהאב: Code, Codespaces, Create codespace on `feat/calm-ai-news`.
2. מצב הדגמה (ללא מפתח, ידיעות בדויות): `npm run demo`. הפורט 3000 ייפתח כתצוגה מקדימה.
3. מצב חי: ב-GitHub, Settings, Secrets and variables, Codespaces, הוסף secret בשם `ANTHROPIC_API_KEY` (לפני יצירת ה-Codespace, או הפעל אותו מחדש). אחר כך `npm run live`. הריצה הראשונה אורכת כמה דקות, כי היא שואבת ומעבדת את כל הידיעות. אחרי זה בדוק את `/api/status` לראות אילו מקורות נכשלו.

## משתני סביבה

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `ANTHROPIC_API_KEY` | | חובה לחדשות אמיתיות |
| `AI_MODEL` | `claude-haiku-4-5-20251001` | המודל לעיבוד |
| `DATA_DIR` | `server/data` (בדוקר: `/data`) | איפה נשמרים הקבצים. חייב להיות volume קבוע |
| `ADMIN_TOKEN` | ריק | מפעיל `POST /api/admin/refresh` עם `Authorization: Bearer <token>`. אם ריק, הנתיב מחזיר 404 |
| `REFRESH_CRON` | `*/30 * * * *` | תדירות ריענון |
| `PORT` | `3000` | |

## פריסה ב-Coolify

- בנייה מה-`Dockerfile` שבשורש.
- הוסף Persistent Storage עם נתיב `/data`, אחרת כל פריסה מוחקת את הידיעות.
- הגדר `ANTHROPIC_API_KEY`. אפשר גם `ADMIN_TOKEN`.
- בדיקת תקינות: `/healthz`. מצב המקורות והעלויות: `/api/status` ו-`meta.json` (טוקנים לכל ריצה).
- מקורות שנוספו ולא אומתו (`verified: false`) עלולים להיכשל. בדוק ב-`/api/status` או בפלט של `npm run refresh`, והסר מ-`sources.js` את מה שלא עובד.
